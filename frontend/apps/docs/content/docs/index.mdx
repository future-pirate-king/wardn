# Wardn

Wardn is a GitOps-first continuous delivery operator for Kubernetes. It syncs your cluster state from Git repositories, eliminating manual deployments and configuration drift.

## Why Wardn?

- **GitOps-native** — Git is the single source of truth for your deployments
- **Multi-cluster** — Manage deployments across clusters from a single control plane
- **Health checks** — Built-in health monitoring with configurable probes
- **Drift detection** — Automatic reconciliation when cluster state diverges
